Shaderfont

재질, 드래그, 자동 등장을 따로 골라 보세요. 드래그 디졸브는 선택한 부분만 지우고, 불타는 등장은 드래그 없이 글자를 드러냅니다.

이 문장은 실제 DOM 텍스트입니다. 직접 고쳐 쓰거나 문장을 드래그해 보세요.
드래그 후 선택을 해제할 때까지 유지 · 현재 상태 idle / dissolve / 0%

재질 크기와 화질
자동 등장 시간

나타난 뒤에는 글자를 온전히 보여 줍니다. 반복 대기를 0으로 두면 한 번만 등장합니다. 재질 속도와 드래그 시간은 바꾸지 않습니다.

재질 샘플

가리키거나 키보드로 포커스하면 움직입니다. 누르면 샘플의 재질과 색상을 위 문장에 적용합니다.

<script type="module" src="/src/shader-font.js"></script>

<shader-font
  shader="hologram"
  renderer="canvas2d"
  drag-effect="dissolve"
  primary="#69efff"
  secondary="#ff946a"
  accent="#fff4bd"
  roughness="0.26"
  dissolve-ms="2400"
  restore-ms="1800">
  안녕하세요
</shader-font>

실제로 쓸 때

shader, drag-effect, reveal-effect는 서로 독립적입니다. 필요한 효과만 켜고 나머지는 none으로 둡니다. 효과는 브라우저의 실제 글자 모양으로 잘라냅니다.

<!-- 일반 글자 + 브라우저 기본 선택 -->
<shader-font shader="none" drag-effect="none">
  평범한 본문
</shader-font>
<!-- 1.8초 등장 + 5초 대기 후 반복 -->
<shader-font shader="none" drag-effect="none"
  reveal-effect="burn" reveal-ms="1800"
  reveal-interval-ms="5000">
  불타는 경계를 따라 나타나는 글자
</shader-font>
<!-- 홀로그램 + 고무줄 드래그 -->
<shader-font shader="hologram" drag-effect="elastic">
  잡아당겨 보세요
</shader-font>

요청한 하이픈 없는 별칭도 자동으로 표준 요소로 바뀝니다.
