DOM typography / sentence-aware dissolve

Shaderfont

실제 DOM 글자를 그대로 편집하면서 디졸브, 이동, 떨림, 고무줄 탄성을 골라 드래그할 수 있습니다. 디졸브의 위치는 선택한 글자, 진행량은 드래그를 유지한 시간이 정합니다.

이 문장은 실제 DOM 텍스트입니다. 직접 고쳐 쓰거나 문장을 드래그해 보세요.
글자를 선택하듯 드래그 · 현재 상태 idle / dissolve / 0%
<script type="module" src="/src/shader-font.js"></script>

<shader-font
  shader="hologram"
  drag-effect="dissolve"
  primary="#69efff"
  secondary="#ff946a"
  accent="#fff4bd"
  roughness="0.26"
  dissolve-ms="1800"
  restore-ms="1800">
  안녕하세요
</shader-font>

실제로 쓸 때

shader와 drag-effect는 서로 독립적입니다. 둘 중 하나만 끄거나, 둘 다 끌 수 있습니다.

<!-- 일반 글자 + 브라우저 기본 선택 -->
<shader-font shader="none" drag-effect="none">
  평범한 본문
</shader-font>
<!-- 홀로그램 + 고무줄 드래그 -->
<shader-font shader="hologram" drag-effect="elastic">
  잡아당겨 보세요
</shader-font>

요청한 하이픈 없는 별칭도 자동으로 표준 요소로 바뀝니다.
